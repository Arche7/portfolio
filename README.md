# Портфолио — Арсений Чертищев

- `index.html` — сайт-портфолио. Открывается двойным щелчком, всё внутри одного файла.
- `portfolio.pdf` — версия для отправки на почту и печати (17 страниц).
- `portfolio.pptx` — презентация для защиты и собеседований (19 слайдов).

## Как добавить свои контакты на сайт
1. Открой `index.html` в VS Code.
2. Нажми `Cmd + F` и найди `const CONFIG`.
3. Впиши ник в `telegram: ''` (без @) и почту в `email: ''`, сохрани файл.
Пустая строка — кнопка не показывается.
